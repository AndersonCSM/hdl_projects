# Skills do Agente

Este documento lista as habilidades necessárias para otimizar as funcionalidades do repositório.

## 1. Análise de Código e Refatoração
- **Descrição**: Capacidade de analisar scripts e estruturas de código existentes para melhorar a performance e legibilidade.
- **Ações**: Otimizar loops, remover redundâncias e aplicar boas práticas de desenvolvimento (Clean Code).

## 2. Documentação e Comentários
- **Descrição**: Garantir que as funcionalidades estejam bem documentadas para que outros desenvolvedores possam entender.
- **Ações**: Adicionar docstrings, atualizar o `README.md` quando novas funcionalidades forem adicionadas.

## 3. Automação de Tarefas
- **Descrição**: Otimizar fluxos de trabalho dentro do repositório.
- **Ações**: Sugerir ou criar scripts para build, testes ou deploy automatizado.

## 4. Resolução de Problemas (Debugging)
- **Descrição**: Encontrar e corrigir falhas de execução.
- **Ações**: Ler logs, rastrear chamadas de funções e propor soluções definitivas.
